Targeted literature for fixed-budget, solve-adaptive kernel preconditioning
Verified 2026-11-23. Scope: CPU solves of (K + lambda I)x = b on synthetic,
Concrete and Airfoil data, retaining k actual kernel columns. This is a bounded
primary-source search, not an exhaustive novelty review. Section/page anchors
below refer to the linked versions; PDF pages count from 1.

Main finding

Changing a Nyström preconditioner within one solve already appears in sGDML.
Flexible CG, deflation, and target-aware incomplete Cholesky are established.
Among the inspected sources, none implements our particular combination of
fixed-cardinality column exchange, selection using unresolved solve information,
and preservation of useful conjugacy. That search result is not a novelty claim.
The meaningful research question is whether this combination pays for itself in
CPU time at a fixed retained-column budget across all three dataset families.

The existing project results separate two failures. Restarting harms progress,
but exchanged versus unchanged preconditioners with equal restarts also lost
every 5- and 10-step branch comparison. Therefore changing the Krylov recurrence
alone does not repair the selection objective. The checkpoint comparisons are
dependent observations, not 60 independent experiments. Evidence:
project/docs/branch-verification.txt and project/docs/initial-observations.tex.

1. Same-solve adaptive Nyström: a direct precedent

Chmiela et al., Accurate Global Machine Learning Force Fields for Molecules with
Hundreds of Atoms, Science Advances 9(2), eadf0873 (2023).
https://doi.org/10.1126/sciadv.adf0873
https://arxiv.org/pdf/2209.14865v3
Anchor: Appendix G(d), PDF p.15 (supplement p.4); Appendix F, PDF p.14.

The solver monitors average residual progress over a rolling window. When
progress stalls, it restarts CG from the current iterate and increases the
number of inducing columns before restarting. Approximate ridge leverage scores
select columns. This is adaptation during the same kernel solve, although the
adaptation increases rank rather than exchanging columns under a fixed cap.

Official implementation, linked from https://sgdml.org/, was inspected:
https://github.com/stefanch/sGDML/blob/master/sgdml/solvers/iterative.py
Anchors: lines 48–51 (window/threshold), 401 (leverage sampling), 614 (status),
730–735 (trigger), 755–798 (restart/rebuild), as inspected on the date above.
Current code uses a 100-step window, effectiveness threshold <=0, and increases
the inducing-point count to ceil(1.2 times its old value). It resamples from
current leverage scores and rebuilds. It explicitly leaves keeping the same
number of points as future work. Do not attribute these implementation constants
to a theorem. A capped, fixed-k rebuild triggered by stagnation would be our
adaptation of this control, not an exact reproduction of their algorithm.

2. Flexible CG: preserve directions when the preconditioner changes

Notay, Flexible Conjugate Gradients, SIAM J. Sci. Comput. 22(4), 1444–1460 (2000).
https://doi.org/10.1137/S1064827599362314
Publisher abstract verified; implementation details below use accessible sources.

Knyazev and Lashuk, Steepest Descent and Conjugate Gradient Methods with Variable
Preconditioning, SIAM J. Matrix Anal. Appl. 29(4), 1267–1280.
https://doi.org/10.1137/060675290
https://arxiv.org/pdf/math/0605767
Anchor: §1, Eq.(1.1)–(1.2), PDF p.2; §5 for worst-case results.

With z_t=M_t^{-1}r_t and retained recent directions p_j,
  p_t = z_t - sum_j p_j (p_j^T A z_t)/(p_j^T A p_j),
  alpha_t = (r_t^T p_t)/(p_t^T A p_t).
Cache p_j and A p_j, so orthogonalization needs inner products, not extra A
applications. A fixed window m_t=min(t,m) satisfies their truncation condition.
Full history gives the diagnostic reference; bounded history is the practical
control. Uniformly bounded SPD preconditioners still permit variable-PCG
worst cases as slow as steepest descent. Flexibility is not a convergence-speed
guarantee for arbitrary column replacements.

Independent official implementation:
https://petsc.org/release/manualpages/KSP/KSPFCG/
https://petsc.org/release/src/ksp/ksp/impls/fcg/fcg.c.html
Anchors: KSPSolve_FCG, source lines 155–205; standard/Notay truncation options.
PETSc explicitly stores search directions and their A-images. Allow about 2mn
extra vector entries, and report this memory separately from k kernel columns.
Use the same history allowance for fixed and adaptive preconditioners. Ordinary
fixed-PCG beta=rho_new/rho_old cannot simply be retained across an arbitrary
preconditioner replacement.

3. Deflation/augmentation: a stronger control for restart damage

Gaul, Gutknecht, Liesen and Nabben, A Framework for Deflated and Augmented Krylov
Subspace Methods, SIAM J. Matrix Anal. Appl. 34(2), 495–518 (2013).
https://doi.org/10.1137/110820713
https://people.math.ethz.ch/~mhg/pub/defl-GGLN1-SIMAX.pdf
Anchors: Theorem 3.2, Eq.(3.11), PDF p.7; §4, Eq.(4.1), PDF pp.9–11.

For a full-rank saved subspace U and E=U^T A U, the standard coarse correction is
  x <- x + U E^{-1} U^T r,
  r <- r - A U E^{-1} U^T r.
The deflated operator is (I-AU E^{-1}U^T)A. Equivalent augmentation preserves
the space U while solving the remaining problem. This supplies a mathematically
defined control for keeping useful spectral information across our checkpoints.
Use a few saved directions or Ritz vectors and cache AU; do not merely restart
with an improved x and call that recycling. Small eigenvalues are a common
deflation target, but relevant modes are those of the preconditioned problem,
not automatically the smallest eigenvectors of the unpreconditioned kernel.
This method stores non-column vectors and has a different memory allocation.
Its benefits cannot be attributed to better landmark selection.

4. Predictive incomplete Cholesky: target-aware columns are established

Bach and Jordan, Predictive Low-Rank Decomposition for Kernel Methods,
ICML 2005, 33–40. DOI: 10.1145/1102351.1102356.
https://icml.cc/Conferences/2005/proceedings/papers/005_Predictive_BachJordan.pdf
Anchors: §3.2 Eq.(2), PDF p.4; §4.3 Eqs.(5)–(8), PDF pp.4–5;
§5 and Figure 1, PDF pp.5–6.

CSI minimizes
  w_K tr(K-GG^T) + w_Y ||(I-QQ^T)Y||_F^2,
where Q spans G, w_K=(1-kappa)/tr(K), w_Y=kappa/||Y||_F^2.
For candidate residual Cholesky column g and h=(I-QQ^T)g, the exact addition
gain is w_K||g||^2 + w_Y||Y^T h||^2/||h||^2. A look-ahead Cholesky factor estimates
gains for unseen columns, avoiding evaluation of every full kernel column.
The algorithm appends columns and uses fixed side information Y. It does not
establish a PCG error reduction guarantee or a fixed-budget exchange rule.

Strong control: initialize rank-k landmarks with CSI using Y=b and solve with
the resulting fixed preconditioner. Rebuilding with Y=r_t is a clearly labeled
residual-driven adaptation of CSI. It should be compared with static CSI;
using a current residual as side information is not sufficient novelty alone.
Preserve zero-gain/dependent-column checks when h nearly vanishes.

5. Adaptive matrix-residual sampling is different from solve-residual sampling

Wang and Zhang, Efficient Algorithms and Error Analysis for the Modified Nyström
Method, AISTATS 2014, PMLR 33, 996–1004.
https://proceedings.mlr.press/v33/wang14c.pdf
Anchor: §4, Algorithms 1–2 and Theorem 3, PDF p.4.

After selecting C, sample column j with probability proportional to
||(I-CC^dagger)K(:,j)||^2. Additional rounds append columns. The approximation
is modified Nyström, C(C^dagger K(C^dagger)^T)C^T, which differs from our
C K[S,S]^dagger C^T. The guarantee concerns matrix approximation, not the
current system residual r=b-Ax. It does not justify probabilities proportional
to r_j^2 or fixed-budget swaps. IterativeCUR's analogous matrix-versus-solve
distinction is already documented in project/docs/iterativecur-notes.txt.
An exact matrix-residual selector is a useful small-instance diagnostic but
must not be presented as a cheap matrix-free control without charging its cost.

6. Spectral normalization: a cheap control using the same retained columns

Frangella, Tropp and Udell, Randomized Nyström Preconditioning,
SIAM J. Matrix Anal. Appl. 44(2), 718–752 (2023).
https://doi.org/10.1137/21M1466244
https://arxiv.org/pdf/2110.02820v2
Anchors: Eq.(1.3), PDF p.2; §5.4.1–5.4.3, PDF pp.14–16.

If Khat=U diag(theta) U^T, with theta_k the smallest retained eigenvalue, their
preconditioner is
  P = U diag((theta+lambda)/(theta_k+lambda)) U^T + I-UU^T.
This changes the relative treatment of the retained space and its complement;
it is not merely a scalar rescaling of our Khat+lambda I. Its inverse is cheap
from the same factor's thin SVD. Test this fixed baseline before claiming an
advantage from online column adaptation.

Their adaptive choices double sketch rank until an estimated matrix error or
theta_k/lambda criterion is met, or take the largest affordable rank. These are
setup decisions, not residual-based within-solve exchanges. The stated random
projection guarantees do not automatically transfer to RPCholesky columns.
Applying the normalized formula to our same column factor is an empirical
control, not a direct theorem-backed reproduction of Gaussian-sketch Nyström.

7. AFN clarifies another meaning of adaptive

Zhao, Xu, Huang, Chow and Xi, An Adaptive Factorized Nyström Preconditioner for
Regularized Kernel Matrices, arXiv:2304.05460v2 (2024).
https://arxiv.org/html/2304.05460v2
Anchors: §3.2 Algorithms 2–3; §3.3 Algorithm 4; §4.5; §5 code links.

AFN uses a landmark block factorization and a sparse approximate inverse for
the remaining Schur complement. It estimates rank from a subsampled kernel,
then chooses landmark points by farthest-point sampling (FPS). Its adaptivity
addresses kernel parameters and numerical rank, not current linear residuals.
FPS repeatedly selects the point farthest from its closest retained landmark;
maintaining nearest distances costs O(dnk). FPS is an inexpensive geometric
fixed-k initialization control. Full AFN carries sparse correction storage,
so it is not an equal column-only-memory baseline.
Official C test routines were verified through the GitHub connector:
https://github.com/scalable-matrix/H2Pack/tree/AFN_precond/examples/AFN_precond
The paper's prose capitalizes the branch differently; the linked URL above
works and contains Nys_precond.c, test_Nys.c and test_AFN.c.

Recommended first implementation comparisons (our synthesis)

Keep the original fixed-k solve objective and all three dataset families.
First separate mechanisms using the already verified checkpoints:
  (a) unchanged preconditioner with continuous PCG;
  (b) unchanged preconditioner with matched restarts;
  (c) unchanged versus exchanged preconditioner with identical truncated FCG;
  (d) a curvature-based exchange decision under that same FCG recurrence.
Then compare total solves against fixed RPCholesky, same-factor normalized
spectral preconditioning, fixed CSI, the existing BFGS control, and a bounded
recycling/deflation control. FPS is an optional inexpensive static check.
These controls explain gains; they do not replace the adaptive project.

For a proposed next direction p, exact squared A-error decrease after line
minimization is (r^T p)^2/(p^T A p). For a restarted step p=M^{-1}r this is
the Delta score already checked in branch-verification.txt. It is invariant
under scalar rescaling of M, unlike q=r^T M^{-1}r. Under FCG, score the actual
A-orthogonalized p, not the unprojected z. The denominator requires A p;
charging one or more full kernel products for each trial can erase a gain.
One-step dominance also does not ensure better multi-step or total solve time.

Plausible research direction, not an established result

Study selection of actual columns for the part of the error that the current
Krylov history has not removed. The joint mechanism would combine bounded
A-orthogonalization with a fixed-cardinality exchange objective evaluated after
that projection. Keep a no-exchange option. This differs substantively from
blindly reducing the inverse quadratic form on the current residual, and from
merely adding FCG to the original selector.

A concrete first candidate is: form a small candidate pool using CSI-style
innovation against a short history of normalized residual/slow-mode vectors;
use cheap low-rank algebra to shortlist exchanges; compare the best proposal
with no exchange using the actual projected one-step energy decrease. Candidate
histories and any extra vectors must be counted. A shortlist chosen solely by
the old q rule is a useful diagnostic gate, but it can miss every beneficial
exchange and is not the final selection mechanism.

The hard contribution would be a low-cost predictor of multi-step benefit and
a retention rule that avoids destroying useful modes, while fitting the fixed
column budget. Curvature scoring, CSI projection gains, flexible CG and
deflation themselves are established ingredients. A claim of a new combined
method requires additional nearest-neighbor checking after its exact rule is
fixed, plus consistent end-to-end speed improvements with all selection,
factor-update, orthogonalization, and verification work charged.

Practical falsification: retain the 5/10/20-step branch measurements, add the
actual projected direction score, and run the whole solve with true residual
stopping on synthetic, Concrete and Airfoil. A method that wins only its own
selection score, or only against restarted weak controls, has not met the
project objective. No speedup or guarantee is claimed by this literature note.

Follow-up: fixed-rank generalized Nyström / secant memory (2026-11-23)

Scope of this follow-up: targeted primary-source checking for replacing some
coordinate probes by current-solve directions. No implementation or numerical
claim. Earlier candidate recommendations above are historical hypotheses;
subsequent failed exchange diagnostics do not support their effectiveness.

1. Exact-line-search SR1 is already linked to PCG.
Forsgren and Odland, On exact linesearch quasi-Newton methods for minimizing a
quadratic function, Computational Optimization and Applications 69 (2018),
225–241, DOI 10.1007/s10589-017-9940-7.
https://link.springer.com/article/10.1007/s10589-017-9940-7
Inspected §4.1 (rank-one updates, including SR1), §5, and §6 (preconditioning).
Their results establish equivalence of appropriate quasi-Newton directions
with CG/PCG on a quadratic under exact line searches; classical SR1 is a
member when its update is well defined. Thus an unevicted SR1 scheme taking
p=M^{-1}r and exact line searches is an equivalence control, not an intrinsic
acceleration mechanism. This statement does not cover arbitrary truncation,
finite precision, skipped updates, or ordinary fixed-PCG beta formulas after
arbitrary changes of M. Our lower-bound construction gives SPD by a stronger
special structure than general SR1 enjoys.

2. Fixed-memory CG curvature sampling predates this proposal.
Morales and Nocedal, Automatic Preconditioning by Limited Memory Quasi-Newton
Updating, SIAM Journal on Optimization 10(4) (2000), 1079–1096,
DOI 10.1137/S1052623497327854.
https://users.iems.northwestern.edu/~nocedal/PDFfiles/autoprecond.pdf
Author PDF: §2, pp.3–5; sampling experiments pp.16–19; SAMPLE appendix
pp.20–21 (PDF page numbers, distinct from journal pagination).
They form limited-memory BFGS preconditioners from CG correction pairs and
compare the last m pairs with approximately uniform temporal sampling. Their
appendix keeps at most m pairs while choosing insertions/deletions. A concluding
small-Rayleigh-quotient policy was also tested without consistent superiority.
The inspected experiments use the collected preconditioner on later RHS or
Newton systems. They do not establish our active same-solve generalized-
Nyström replacement rule. Nevertheless, CG curvature reuse, limited memory,
and selecting non-FIFO pairs cannot be claimed individually as new.

3. Compact SR1 and FIFO deletion are established preconditioner machinery.
Bergamaschi, Marín and Martínez, Compact Quasi-Newton Preconditioners for SPD
linear systems, arXiv:2001.01062v1 (2020), inspected author manuscript.
https://arxiv.org/html/2001.01062
https://www.dmsa.unipd.it/~berga/Research/Recenti/bmm2019.pdf
§3.3–3.5, PDF pp.9–10, Eqs.(3.17)–(3.19): compact inverse SR1 representation,
small-denominator skip rule, and deletion of the oldest stored vector/core
row and column. Updates occur before PCG solves successive Newton systems,
not between iterations of the same fixed system. This supplies an established
limited-memory control; their general SPD conditions are not needed to prove
SPD of a shifted PSD Nyström approximation.

4. Krylov Nyström preconditioning is already explicit in recent theory.
Chen, Huber, Lin and Zaid, Preconditioning without a preconditioner using
randomized block Krylov subspace methods, ETNA 65 (2026), 63–92,
DOI 10.1553/etna_vol65s63.
https://etna.ricam.oeaw.ac.at/vol.65.2026/pp63-92.dir/pp63-92.pdf
§2.2.2 Eq.(2.3), printed p.67: generalized Nyström on
V=[Ω,AΩ,...,A^{s-1}Ω], Ahat=AV(V^TAV)^dagger V^TA.
§3.1 Theorem 3.3, p.69: augmented block CG with starting block [b,Ω]
dominates a broad fixed-preconditioner class after comparable matrix loads.
§3.2, p.70 explicitly limits the comparison: no corresponding dominance in
scalar matrix-vector products or floating-point cost. The paper does not give
our rank-k eviction policy. Its construction also generally accumulates block
Krylov information rather than maintaining exactly k active probes.

5. Nyström retaining history and secant information has direct prior art.
Hu, Jiang, Lin, Wen and Yuan, Structured Quasi-Newton Methods for Optimization
with Orthogonality Constraints, SISC 41(4) (2019), A2239–A2269,
DOI 10.1137/18M121112X. Inspected arXiv:1809.00452v1 author PDF:
https://math.berkeley.edu/~linlin/publications/QN_OPT.pdf
§2.3, PDF pp.6–7, Eqs.(2.10)–(2.11): limited-memory Nyström approximation
of an expensive operator part, with sketch space containing iterate history
and optionally an operator image; preserving the secant subspace preserves
the associated secant condition. This is orthogonality-constrained nonlinear
optimization, not fixed-k kernel PCG. It rules out a broad claim that history-
adapted or secant-preserving Nyström itself is new.

Screened near miss: Lifshitz et al., L-SR1: Learned Symmetric-Rank-One
Preconditioning, ICML 2026, https://proceedings.mlr.press/v306/lifshitz26a.html
and https://arxiv.org/html/2508.12270v2 . §4 uses a learned nonlinear optimizer,
a bounded FIFO buffer, and a PSD parameterization with a secant training
penalty. It does not supply exact same-solve Nyström interpolation or our
kernel-sketch replacement rule. “Learned” in that title means meta-training.

Mechanism identities and limits (our algebraic synthesis, not novelty claims)

For K>=0, Ω with nonsingular W=Ω^TKΩ, Y=KΩ, let Khat=YW^{-1}Y^T.
Appending p gives u=(K-Khat)p and δ=p^Tu. If δ>0, then
  Khat_new=Khat+uu^T/δ.
For A=K+λI and M=Khat+λI, this is the standard direct SR1 secant update
with y=Ap, s=p. It preserves 0<=Khat_new<=K and interpolates every retained
probe. The denominator-zero case carries no new K-information and must be
handled as a rank-deficiency case, not repaired by claiming a positive gain.

If a retained p obeys Mp=Ap and p^Tr=0, then p^TA M^{-1}r=0. Thus retained
secants encode conjugacy against the preconditioned residual. This alone does
not establish conjugacy against evicted directions, a complete three-term
recurrence, or faster convergence. Generic spectral compression also need
not preserve individual secants unless those directions remain in its span.

For an augmented sketch with inverse core G=W^{-1}, define
  d_j=Y G e_j / sqrt(G_jj).
Deleting probe j gives Khat_without_j=Khat_full-d_j d_j^T. Therefore its
trace loss is ||d_j||^2 and its shifted logdet loss is
  -log(1-d_j^T M_full^{-1}d_j), M_full=λI+Khat_full.
These are elementary Schur-complement and determinant-lemma identities.
Use trace(Khat) or logdet(M), not logdet(W): the latter depends arbitrarily
on the scale of mixed coordinate and CG probes. Such global objectives
still do not measure remaining solve error or preservation of recurrence.

The defensible open question in this bounded search is whether a fixed total
memory budget can be allocated between initial coordinate information and
same-solve secants to improve end-to-end CPU solve time. The exact eviction
rule, including which secants it must protect and when it accepts an update,
would carry any contribution. First controls should separate no-eviction SR1
equivalence, FIFO retention, uniform temporal retention, and invariant global
trace/logdet selection. All comparisons must charge sketch/core maintenance,
inverse application, and true-residual verification and retain synthetic,
Concrete and Airfoil. Once probes become dense p vectors, the constraint is
a fixed retained-sketch rank/memory budget; calling it fixed actual-column
selection would misstate the method. No inspected source was the identical
mixed-probe same-solve eviction scheme, but that is a bounded search result,
not proof of novelty or practical usefulness.

Concept check: compress during warm-up, freeze, restart (2026-11-23)

Inspected scripts/check_probe_compression_restart.py and
src/nystrom_project/learning.py read-only. Current mechanism: initialize from
RPCholesky columns, append the SR1/Nyström innovation obtained from an existing
solve product Kp=Ap−λp, truncate the augmented factor to rank k, repeat during
a short initial solve phase, then freeze and restart. The prototype uses
one-direction flexible orthogonalization during learning. The conceptual
review does not assess the reported timing or iteration evidence.

https://proceedings.neurips.cc/paper_files/paper/2017/file/4558dbb6f6f8bb2e16d03b85bde76e2c-Paper.pdf

Huh, Cartis and Nakatsukasa, Adaptive LSQR Preconditioning from One Small

https://arxiv.org/html/2604.05065v1
§3.2.1–3.2.2, Algorithm 1, and §5.1: APLICUR interleaves warm-started LSQR

Concept verdict: revise framing and continue development. The method is
coherent and relevant to the specific fixed-memory kernel-solve problem.
Its mathematical primitives are established; no identical full loop was found
in this targeted primary-source search. The remaining algorithmic distinction
is current-solve acquisition and forgetting under a fixed sketch budget,
followed by a transition to a fixed preconditioner. This is presently a modest
method variation with development potential, not an established new class of
Nyström or quasi-Newton method. Confidence is high on the component overlap,
moderate on the absence of an identical complete loop.

C1 — Scope/identity: dense learned probes replace actual coordinate columns.
Smallest repair: call the main method fixed-rank/fixed-memory sketch learning;
keep the final QR column-selection branch as a separate actual-column variant.

C2 — Meaning of optimality: the SVD is optimal for the current rank-(k+1)
surrogate, not for K itself or for the union of all previously observed
directions. Repeated truncation has forgotten information. Smallest repair:
state local surrogate optimality and describe the method as online compression.

C3 — Causal claim: rank truncation can alter the fixed-PCG trajectory, but
breaking an equivalence is not itself a new insight or a convergence benefit.
The retained-trace increase measures matrix approximation, not remaining solve
error. The meaningful hypothesis is that solve-selected observations improve
the useful spectral coverage enough to justify compression and one restart.
Smallest repair: put that acquisition/forgetting tradeoff at the center of the
problem statement; do not present an arbitrary ten-step limit as adaptivity.

Exact-arithmetic identity explaining the representation (our derivation):
write F=KS with S^TKS=I. The innovation is Kq, where
  q=(p−S F^T p)/sqrt(p^TKp−||F^Tp||^2).
Then [S,q] remains K-orthonormal. Truncating F_aug by its top k right singular
vectors V_k gives F_new=F_aug V_k=K S_new with S_new=[S,q]V_k and
S_new^TKS_new=I. Therefore the state is still generalized Nyström on a rotated
probe space, with 0<=F_new F_new^T<=K. Individual old secants need not survive.
This explains validity; it is an elementary identity, not a novelty claim.

A concrete refinement is to separate acquisition from application: maintain
the same rank-k shadow sketch from ordinary initial fixed-PCG products, then
apply it only at the learning-to-solving transition. This preserves the warm-up
recurrence and makes the learned-sketch contribution distinct from changing
the solver during acquisition. It is an established-style design refinement,
not a new claim by itself. A stronger research contribution would specify a
principled learning/freeze policy using observed innovation and its retained
fraction relative to the regularization scale, rather than only selecting a
fixed number of early steps. Such a policy still needs comparison with the
rank/schedule adaptivity already present in APLICUR; generic 'adaptive stopping'
would not be an adequate novelty statement. Preserve the same dataset and
regularization scope while resolving this conceptual distinction.

Targeted FSAI-pattern verification (2026-11-23)

Question: does existing work already perform fixed-row-cardinality exchanges
during one kernel solve, recompute canonical FSAI coefficients from local Schur
submatrices, and select exchanges by the current Schur-residual inverse-action
energy J(z)=z^TSz−2q^Tz, z=G^TGq? This is a mechanism lookup, not a new concept
review or a novelty conclusion.

Brarda, Xu, Kalantzis, Li and Xi, Factored Sparse Approximate Inverse
Preconditioning via Spectral Optimization, arXiv:2606.22742v1 (22 June 2026).
https://arxiv.org/html/2606.22742v1
Inspected §§2–4 and §5.2. This paper PRESCRIBES the support of G and optimizes
its admissible VALUES through L_f(G)=tr(f(G^TAG))/n. It uses global spectral
losses, with SLQ/Lanczos estimates and projected support-gradients; the small
tests use exact eigendecompositions. §5.2 optimizes a factor with L-BFGS, then
evaluates it in FGMRES solves. It neither swaps support positions nor selects
changes from a current linear-system residual. Its principal distinction is
spectral value selection, especially a bimodal objective for indefinite
systems. Our canonical local FSAI coefficients and residual-driven support
choice are different operations.

Jia, A residual based sparse approximate inverse preconditioning procedure
for large sparse linear systems, NLAA 24(2) (2017), e2080,
DOI 10.1002/nla.2080.
https://onlinelibrary.wiley.com/doi/10.1002/nla.2080
Published abstract verified. Related full preprint inspected:
https://arxiv.org/html/1503.04500v2 (Jia and Kang; do not merge author lists).
§2, §3 and Algorithm 1 explicitly define the residual as r_j=A m_j−e_j,

the solve residual b−Ax. The published RSAI(fix) abstract allows repositioning

RSAI(tol) drops small entries by a tolerance. Therefore “fix” does not establish
the constant-b-per-row same-solve operation. Full published RSAI(fix) algorithm
was not available in the inspected primary text; its precise details beyond
the abstract remain unverified.

Huckle and Kallischko, Frobenius norm minimization and probing for

DOI 10.1080/00207160701396387.
https://www.tandfonline.com/doi/abs/10.1080/00207160701396387
https://portal.fis.tum.de/de/publications/frobenius-norm-minimization-and-probing-for-preconditioning/

Algebraic obstacle (our deduction, exact arithmetic, fixed preconditioner):
write C=M^-1/2 A M^-1/2 and let V_t be the CG/Lanczos search basis. Current

can have additional boundary terms, which must be identified rather than
assumed to estimate slow error. With M=Khat+lambda I <= A, generalized
eigenvalues are >=1; selecting the lowest Ritz values is not automatically
selecting the poorly preconditioned modes.

Bounded follow-up: exact spectral guard for one landmark exchange
(2026-11-23; targeted lookup, no production code changes)

Actionable result (our algebraic derivation, not a novelty claim):
Assume K is PSD, lambda>0, and M=Khat+lambda I with exact untruncated
Nyström interpolation. For an exchange, let C be the shared k-1 landmarks,
R_C=K-Khat_C, a=R_C[:,old]/sqrt(R_C[old,old]), and
b=R_C[:,new]/sqrt(R_C[new,new]). Zero residual diagonals denote redundant
columns and need the corresponding zero increment. Then
  Khat_old=Khat_C+a*a^T, Khat_new=Khat_C+b*b^T,
  M_new=M_old+b*b^T-a*a^T.
With H=M_old^-1, alpha=a^T H a, beta=b^T H b, gamma=a^T H b,
the only possibly nonunit eigenvalues of M_old^-1/2 M_new M_old^-1/2 are
  ell=1+(beta-alpha-sqrt((alpha+beta)^2-4 gamma^2))/2,
  u  =1+(beta-alpha+sqrt((alpha+beta)^2-4 gamma^2))/2.
For n>=2 these are the exact extrema (including any zero/rank-one
 degeneracies); ell<=1<=u. The nonzero eigenvalues of vv^T-uu^T have
sum beta-alpha and product gamma^2-alpha*beta, which proves the formula.
In particular ell*M_old <= M_new <= u*M_old, and for any SPD A,
  kappa(M_new^-1 A) <= (u/ell)*kappa(M_old^-1 A).
A cap on u/ell therefore rejects globally violent exchanges, even if a
current-residual score approves them. It costs two applications of the
existing low-rank inverse and a few dot products once a,b are available;
no extra K matvec is required beyond acquiring the candidate column.
O(nk) inverse-application work, plus cost of common-core residual columns.
This formula does NOT cover the FTU normalized spectral preconditioner
without modification. It also does not prove faster current-solve CG.
Repeated stepwise caps multiply; they do not provide a uniform bound
relative to the original preconditioner without tracking accumulated change.

Our deductions / implementation constraints:
Let H0=M^-1, U^T M U=I, T=U^T A U>0. Then the proposed
H=H0+U(T^-1-I)U^T is SPD, by whitening with M^(1/2).
Mapping selected eigenvalues exactly to one requires AU=MU T, not merely
the Ritz condition. A correct positive T alone does not imply acceleration.
At the checkpoint, U in the old PCG space gives U^T r=0 in exact arithmetic,
so the additive correction is initially inactive. Subsequent behavior must
be measured; it is not equivalent to preserving the full old-space projector.

An m-step prefix replay reconstructs d vectors with O(nd+md+m) storage
plus O(n) recurrence workspace, approximately m extra A products/H0
applications, and O(nmd) accumulation work. Count U on top of the original
k actual columns; a fixed k+d storage comparison needs matched baselines.
The second pass must replay the same fixed operator/preconditioner and
recurrence arithmetic. Do not assume recomputing a mathematically equivalent
CG/Lanczos recurrence produces bitwise-identical vectors. Adding new
reorthogonalization corrections in pass two changes the basis, invalidating
unadjusted first-pass Ritz coefficients.

Ghost Ritz values require checking the reconstructed M-Gram matrix, rank
revealing/orthonormalizing the retained block, and recomputing its small
Rayleigh matrix and actual generalized Ritz residuals. Small tridiagonal
residual estimates alone do not verify these finite-precision properties.
A generic balanced control can cache AU; the d+1 boundary-vector shortcut
needs a verified low-rank Lanczos residual relation, which may fail after
loss of orthogonality or ad hoc basis repair.

Useful next comparison: same reconstructed U with spectral-LMP versus
balanced Ritz-LMP, both restarted from the same true residual; include
ordinary restarted H0-PCG, uninterrupted H0-PCG, and a memory-matched Lan-DR
control. Before CPU work, require saved continuation A-products to exceed
the roughly m replay products, then charge replay, orthogonalization,
verification, and the O(nd) per-step correction. Combining known spectral
LMP, same-solve recycling, and two-pass reconstruction does not establish a
new mechanism; any claim needs a distinct selection/budget policy and a
measured same-solve advantage under the full cost/storage accounting.


Bounded follow-up: interleaving two Nyström passes and two solve steps
(2026-11-23)

Candidate, not a result: first compute K[Omega,b], form H1 and take one
unpreconditioned step along b; second compute K[Q,p], Q=orth(K Omega),
p=H1 r1 made A-conjugate to b; form generalized Nyström on [Q,p], truncate
to rank k, freeze. Here A=K+lambda I and x0=0.

Exact information equivalence (our derivation): for an ordinary Nyström
inverse H1=a I+Q D Q^T, a>0, the first step gives
r1=(1-alpha lambda)b-alpha Kb. Therefore
p=Qd+c b-a alpha Kb
for some d,c, including the A-conjugacy correction in c. Modulo range(Q),
p is a scalar multiple of Kb-tau b, tau=c/(a alpha). Consequently the
final untruncated Nyström approximation is exactly generalized Nyström on
[K Omega,Kb-tau b], by basis invariance. It is generally different from
Nyström on [K Omega,Kb], but not a source of arbitrary new Krylov information.
Also [Q,b,p] spans [K Omega,b,Kb], provided the extra direction is nonzero.

The second queried image obeys
Kp=KQ d+c Kb-a alpha K^2 b.
Thus, using cached Kb, each second-pass block determines the other: querying
K[Q,p] versus querying K*orth([K Omega,Kb]) has identical exact operator-
information content when a alpha is nonzero. The static augmented power
pass can reconstruct the same p, Kp and second solve step. Conversely the
candidate can reconstruct K^2 b. Numerical cancellation can break practical
accuracy of these conversions, so an implementation must check it rather
than assume bitwise equivalence.

Mechanism audit: streamed implicit Nyström inverse statistics (2026-11-24)

Scope: derivation plus one tiny independent dense arithmetic check, not a
new solver, benchmark, or novelty claim. No production source changed.
Let C=K[:,S], W=K[S,S]>0, G=C^T C, A=K+lambda I, and
M=lambda I+C W^-1 C^T. Define B=G+lambda W and c=C^T r. Then
  M^-1 r = (r-C beta)/lambda,  beta=B^-1 c.
Thus storing indices and small cores can replace retained n-by-m factors,
at the cost of reconstructing C beta when applying the inverse. Initial G
and c must exist before the first such inverse application; they cannot be
computed from a first PCG product whose direction itself requires them.
A prior setup pass or explicitly different first step is necessary.

In a row-block Kp pass, K[I,:] gives C[I,:] and finalized
ap[I]=K[I,:]p+lambda p[I]. Accumulate d += C[I,:]^T ap[I].
After the global denominator determines alpha, update
  r_new=r-alpha ap, c_new=c-alpha d.
No additional kernel entries are required for this projection update.
For a candidate bank T fixed before the pass, the same rows also supply
C_T^T r_old, C_T^T ap, C_S^T C_T and C_T^T C_T. Small kernel cores can be
gathered from these entries. Candidates may be admitted after alpha is
known, using c_T,new=C_T^T r_old-alpha C_T^T ap. Candidates selected only
after the pass cannot retroactively contribute through discarded rows.
Old fixed-set Grams need not be rebuilt. Cross-Gram work for q proposed
columns costs O(n*m*q+n*q^2) arithmetic even though entry access is shared.

Causality: beta_new depends on completed dot products, alpha and possibly
post-pass admission. Therefore it is not available when earlier row blocks
are discarded. The next C beta_new generally requires O(n*m) selected-column
entry reevaluation, processed in small row blocks. An available Kp is not
a general substitute. Fusing C beta into K(p+E_S beta) works only if beta
is already known before that pass and does not produce both separate
products automatically. Column-oriented traversal can fuse construction
of the new direction into its matrix product, but then Ap rows are not
finalized until the end; C^T Ap cannot be streamed from the discarded C
rows by the same procedure. This shifts the dependency rather than
eliminating both required actions. Retaining C actions for a basis spanning
all possible next beta vectors works, but in the general case restores
O(n*m) storage. Special invariant-subspace or dependent-coefficient cases
do not justify a general elimination claim.

Memory beyond the existing solver vectors: O(m^2) old small cores,
O(m*q+q^2) candidate statistics, O(block_rows*(m+q)) selected-column
workspace. The existing full-kernel block buffer remains O(block_rows*n).
This is a retained-state observation, not a claim that an RP initializer
or any existing implementation already avoids its temporary n-by-m arrays.
For singular/near-singular W, use its rank-revealing small eigendecomposition:
R=V_r Lambda_r^-1/2, beta=R(lambda I+R^T G R)^-1 R^T c.
The formal full-rank B inverse is not a safe substitute for rank handling.

Drift/reset: recursive c updates can diverge from C^T r, especially as both
quantities approach zero. Each existing Kp pass can also accumulate C^T r_old
from the stored residual, costing O(n*m) extra reductions and no kernel
queries; this limits projection drift to the current update. It does not
repair drift of r from b-Ax. A true-residual verification pass for Ax can
jointly recompute r_true and C^T r_true while its rows are available, with
one full kernel pass and no extra selected-column entries. A standalone
projection reset against stored r costs n*m entries and leaves residual
drift untouched; a subsequent C beta still needs its own action unless C
is retained. Forming (r-C beta)/lambda may amplify cancellation at small
lambda. Changing S also changes the preconditioner; these identities do
not establish preservation of a fixed-PCG trajectory.

Our exact-arithmetic derivation:
Let Z=X/bw, s_i=||Z_i||^2, D_ii=exp(-s_i/2), and
 K_p=D*[sum_{j=0}^p (Z*Z^T)^{Hadamard j}/j!]*D.
Every summand is a feature Gram matrix. Consequently
 0 <= K_p <= K_{p+1} <= K,  M_p=K_p+lambda*I is SPD,
 and E_p=A-M_p is PSD.
The omitted diagonal and its trace are
 e_i=1-exp(-s_i)*sum_{j=0}^p s_i^j/j!,  tau_p=sum_i e_i.
Hence ||E_p||_2<=tau_p and
 spec(M_p^{-1/2}*A*M_p^{-1/2}) is contained in

by recurrence, or n scalar tail-function evaluations. Small tails need
stable evaluation rather than subtraction of nearly equal numbers.

tail has spectral radius below one. tau_p<lambda is sufficient, not

 ||r_new||/||r|| <= eta+(1+eta)*tau_p/lambda.
Observed small ||E_p*z|| for one correction does not certify the next.

H1=2H0-H0 C H0. Then
 C^-1-H1=(I-H0 C) C^-1 (I-C H0) >=0.
For any independent columns S, set W=(I-H0 C)S, T=S^T C S.
Since S T^-1 S^T <= C^-1,
 H1 <= H1+W T^-1 W^T <= C^-1.
Thus the associated Schur operator remains at least the exact Schur
operator in exact arithmetic. H1 itself need not be positive for this
Schur ordering. This is symmetric two-level preconditioning machinery,
not a new principle.

An acquisition route uses existing first-refinement work. On core RHS t,
z=H0t, r=t-Cz, delta=H0r are already computed, and delta=(I-H0 C)z.
Archive S=[z_i], W=[delta_i]; T cross terms use already computed Cz_i.
No additional core products or half-solves are required. Normalizing or
dropping columns must transform S and W together. Keep C and H0 fixed
throughout collection. After freezing, S may be freed. Archive storage,
small Gram construction, low-rank application and the changed-Schur
restart are real costs. The next diagnostic compares four such current
core directions to static random acquisition and larger static cores.
This differs from the prior one-pair BFGS core fit and from full-system
quantized-eigenbasis balanced deflation, but its practical benefit and
research novelty are unestablished.
